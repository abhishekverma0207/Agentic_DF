# -----------------------
# Ray PIN — Databricks compatibility
# -----------------------
# Databricks Runtime (DBR) ships Ray 2.9.0 baked into the cluster.  CrewAI
# and its transitive deps will silently pull a NEWER Ray (e.g. 2.30.0) at
# install time, which then fails at run time with:
#     RuntimeError: Version mismatch:
#         The cluster was started with: Ray: 2.9.0
#         This process on node ... was started with: Ray: 2.30.0
# because Ray's head/worker nodes are already initialised on the older
# version and the new Ray code in site-packages can't talk to them.
#
# Pinning Ray to the DBR-shipped 2.9.0 line keeps pip from upgrading it
# during install.  If you ever migrate to a DBR version that ships a
# different Ray (e.g. DBR 16+ with Ray 2.32+), update both this pin and
# any cluster libraries to match.
ray==2.9.0

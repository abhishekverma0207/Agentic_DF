FEU-Agentic Forecasting

LLM-Powered Demand Forecasting Pipeline for FMCG/CPG

Overview

Enterprise-grade demand forecasting system combining CrewAI agents for intelligent analysis with deterministic ML execution for core computation. Designed for DACH (Germany/Austria/Switzerland) category data with full generalization support for any time-series forecasting domain.

Core Capability: End-to-end pipeline supporting 35+ model families, automatic feature engineering, hierarchical reconciliation, and multi-horizon direct forecasting with walk-forward cross-validation.

Intelligent Feature Engineering

Leakage-free pipeline with ACF-informed lags, rolling statistics, seasonal decomposition, hierarchy temporal features, regime detection, and history embeddings—all automatically optimized per segment.

Auto Feature Availability Detection

Classifies every feature as known_in_future, history_only, partially_known, or excluded. History-only features converted to frozen key-level embeddings for inference.

Hierarchical Modeling & Reconciliation

5 reconciliation methods (MinT, bottom-up, WLS, OLS, top-down). Supports global-local, mixed-effects, and multi-level ensemble models for coherent cross-hierarchy forecasts.

Demand Pattern Intelligence

Syntetos-Boylan classification (smooth/erratic/intermittent/lumpy). Intermittency-aware segmentation prevents mixing regular and sparse keys in same segment.

Multi-Horizon Direct Forecasting

Direct h-step forecasting with horizon-specific models. Includes lag-specific bias calibration for accurate long-horizon predictions.

Bias Calibration & Correction

Segment × zero_fraction and lag-specific calibration factors learned from validation. Reduces systematic bias across demand types and forecast horizons.

Pipeline Architecture

8-Stage Sequential Workflow:

  • EDA → Pattern classification, seasonality detection, ACF analysis
  • Feature Availability → Auto-classify feature temporal availability
  • Segmentation → GMM/KMeans clustering + hybrid business dimensions
  • Feature Engineering → Deterministic feature pipeline with leakage prevention
  • Model Training → 35+ model registry with intelligent model-level allocation
  • Inference → Forward forecast + hierarchical reconciliation
  • Diagnostics → WAPE metrics, accuracy analysis, deployment readiness
  • Backtesting → Rolling-origin validation across forecast origins

3 Run Modes: Full pipeline (backtest + forecast) | Forecast-only (no validation) | Backtest-only (no forward forecast)

Deployment Options

Local (AWS Bedrock)

Single-command execution with AWS credentials. Ideal for development, prototyping, and small-scale forecasting.

python runner.py --config config/config_de_skincare.yaml

Enterprise (Databricks)

Full integration with Databricks Workspace. Handles dependency installation and path resolution automatically. Scales to production workloads.

python databricks_runner.py --config /Workspace/.../config.yaml

Key Innovations

  • ✓ Leakage-Free Features: All derived features automatically shifted by forecast_lag to prevent look-ahead bias
  • ✓ Intelligent Model Allocation: Per-key vs pooled model decisions based on data sufficiency, volume, forecastability, uniqueness
  • ✓ Hybrid Segmentation: Statistical clustering + business-domain dimensions + intermittency-aware merging
  • ✓ LLM-Driven Insights: CrewAI agents provide reasoning, recommendations, and human-readable explanations throughout pipeline
  • ✓ Production-Ready Reconciliation: MinT shrinkage ensures coherent multi-level forecasts while minimizing variance
  • ✓ Bias-Aware Forecasting: Dual calibration (segment × zero_fraction + lag-specific) reduces systematic error
